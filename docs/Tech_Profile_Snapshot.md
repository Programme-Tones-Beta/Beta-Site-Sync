# Tech Profile & Core Glossary

## 🎯 Target Career Paths
- **User Experience (UX) Researcher:** Analyzing human behavior, structural pain points, and clipboard patterns.
- **Technical Business Analyst (BA):** Translating real-world operational problems into software data fields.

## 📖 Plain English Tech Glossary
- **CLI:** Command Line Interface.
- **EF Core:** Entity Framework Core—a smart translation layer between C# code and database engines.
- **MAUI:** Multi-platform App UI—.NET's tool for building apps that run on phones and computers using one code foundation.
- **Schema:** The blueprint mapping out structural data relations.
